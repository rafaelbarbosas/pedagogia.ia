# ADR-004 — PostgreSQL com preferência por Neon

- **Status:** Aceita
- **Data:** 2026-08-19

## Contexto

O MVP precisa de atividades públicas estruturadas e filtros SQL de baixo custo.

## Decisão

Usar PostgreSQL, preferencialmente Neon para hospedagem.

## Consequências

SQL e migrations bastam; custos do provedor devem ser monitorados e não haverá banco vetorial.

## Alternativas rejeitadas

Qualquer alternativa que contradiga a decisão definida pelo produto foi rejeitada para o MVP. Reabertura exige impedimento técnico grave e novo registro humano.
