# ADR-011 — BNCC estruturada fora do MVP

- **Status:** Aceita
- **Data:** 2026-08-19

## Contexto

Modelar BNCC exige taxonomia, curadoria e manutenção que não são necessárias à hipótese inicial.

## Decisão

Não criar entidades ou ingestão estruturada de BNCC no MVP.

## Consequências

Reduz complexidade; referências editoriais só podem ser usadas com origem/licença adequadas e sem representar uma base estruturada.

## Alternativas rejeitadas

Qualquer alternativa que contradiga a decisão definida pelo produto foi rejeitada para o MVP. Reabertura exige impedimento técnico grave e novo registro humano.
