# ADR-001 — Manter Angular

- **Status:** Aceita
- **Data:** 2026-08-19

## Contexto

O frontend existente é Angular 19 e contém ativos e páginas reaproveitáveis.

## Decisão

Manter Angular e evoluir a aplicação incrementalmente.

## Consequências

Evita reescrita, preserva conhecimento e reduz risco; exige remover fluxos antigos sem criar novo chat.

## Alternativas rejeitadas

Qualquer alternativa que contradiga a decisão definida pelo produto foi rejeitada para o MVP. Reabertura exige impedimento técnico grave e novo registro humano.
