# ADR-010 — Site Angular como vitrine e tutorial

- **Status:** Aceita
- **Data:** 2026-08-19

## Contexto

No MVP o site deve explicar e habilitar a experiência realizada no ChatGPT.

## Decisão

Limitar Angular a landing, tutorial, instalação, uso, exemplos e documentação básica.

## Consequências

Gerador, feedback e auth ficam obsoletos; não será criado chat próprio.

## Alternativas rejeitadas

Qualquer alternativa que contradiga a decisão definida pelo produto foi rejeitada para o MVP. Reabertura exige impedimento técnico grave e novo registro humano.
